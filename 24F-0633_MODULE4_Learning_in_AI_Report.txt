- Activation experiments: raw_score/sigmoid/tanh for perceptron; linear/sigmoid/tanh for delta rule.

Reflection Questions
1. Key differences:
   The perceptron updates weights only when a sample is misclassified, while the delta rule minimizes
   a continuous loss using gradient descent. The perceptron is discrete and boundary-focused; the delta
   rule provides smoother optimization and explicit loss tracking.
2. Impact of activation functions:
   In this implementation, monotonic score transforms did not change perceptron predictions because
   argmax ranking stayed the same. The delta rule was much more sensitive: linear output was the weakest,
   while sigmoid and tanh reached the strongest test results.
3. Learning-rate adjustment strategy:
   Sweep from small to moderate values, keep inputs standardized, and reject unstable rates. This run
   showed that overly large linear-output updates can diverge, while tanh and sigmoid benefited from
   larger but still controlled learning rates.
4. Implications of train/test ratio:
   The required 80/20 split created 120 training samples and 30 test samples. A larger
   training share improves learning stability but reduces evaluation depth; a larger test share gives a
   stronger estimate of generalization but leaves less data for fitting.
5. Implementation challenges:
   The main issues were extending binary rules to three classes, matching target encodings with activation
   ranges, and preventing numerical overflow. These were handled with a multiclass perceptron, one-vs-rest
   delta targets, standardized features, and clipped sigmoid inputs.
6. Strengths and limitations observed:
   The best perceptron run reached train/test accuracy 0.9833/1.0000
   and learned a strong decision boundary quickly, but it does not optimize a smooth objective. The best
   delta-rule run reached 0.9583/1.0000, offered more tuning
   control through activation and learning-rate choice, and exposed optimization behavior through loss values.
